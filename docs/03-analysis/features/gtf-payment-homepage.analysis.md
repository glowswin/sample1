## 3. Interaction & UX Quality Checklist

1. **국가별 결제수단 탭 필터링**: 전체, 중국, 일본&홍콩, 동남아 4개국 실시간 필터링 정상 작동.
2. **실시간 수수료 시뮬레이터**: 슬라이더 조작 시 타사(1.5%) 대비 GTF(0.9%) 월/연간 절감액 실시간 계산 및 UI 갱신 정상 작동.
3. **브로셔 원본 모달 갤러리**: 4개 이미지 간 탭 전환, 이전/다음 화살표, ESC 닫기 키보드 접근성 완료.
4. **상담 신청 폼**: 필수값 유효성 검사, 로컬 스토리지(`localStorage`) 데이터 적재, 확인 모달 팝업 완료.
5. **모바일 최적화**: 햄버거 메뉴 슬라이드 오버레이, 터치 친화적 버튼, 뷰포트 반응형 완료.
